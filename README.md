# BBR – Blackwattle Bay Railway

This is a simple train network visual simulation built in Typescript, largely by Claude Code, and with an SVG front end that shows trains moving around a mythical scaled-up rail network based on locations near my home.

I like train networks (more than the trains themselves) so this was a nice little exercise in creating my own train set and tweaking the network parameters like number of platforms and tracks, seeing where the bottlenecks occur, and iterating.

Read [CLAUDE.md](CLAUDE.md) for details on how it all works. I'm not really a TypeScript developer and I didn't know you could do the graphics so easily using SVG in the browser.
